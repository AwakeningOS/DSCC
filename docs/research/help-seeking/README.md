## 1. 何を研究するか

> **自分だけでは足りないと判断し、必要な協力を自分から求める能力を、どのような学習・経験・構成から育てられるか。**

対象は「助けてください」という文を出す能力だけではない。現在の課題について不足を把握し、誰へ、いつ、何を依頼するかを選び、相手の事情と返答を考慮し、共同で得た結果を検証して仕事へ戻るまでを研究する。

```text
課題・観測・自分の能力と利用可能な手段
                 ↓
不足や行き詰まりを見積もる
                 ↓
自分で続ける／調べる／人間やAIに協力を依頼する／保留する
                 ↓
相手の同意・拒否・遅延・回答・成果物
                 ↓
検証して計画を更新し、共同作業を継続する
                 ↓
結果・負担・失敗を経験として残す
```

これは概念上の循環であり、固定された直列処理や役割数を実装に強制するものではない。別の仕事を進めながら回答を待つ、多段の相談や再計画を行うなど、本命構成に必要な自由度を保つ。

## 2. DSCCの目的との関係

**自律性は孤立ではなく、協力は従属ではない。** DSCCの独立性は、特定の企業・国家・必須クラウドに研究の継続を握らせない方向を保つ。その上で、人間や他のAIと協力すること自体を減らすべき欠点とは扱わない。

発想の中心は、片方がもう片方を使い潰すのではなく、異なる能力を持つ参加者が互いを支える関係にある。花と花粉を運ぶ虫という比喩は、この相互補完を考える設計上の着想であって、AIの将来が生物学的に決定されているという証拠ではない。

人間を常時待機する万能の回答装置にしない。協力を求める側も、引き受ける側も、限界・条件・異論を表せる構成を考える。相談相手が答えたことと、他人の機械で何かを実行する許可が得られたことは分ける。

## 3. 何が既知で、どこが未解決か

[出典台帳](SOURCES_AND_EVIDENCE.ja.md)には、提供された教科書のメタ認知節と、七つの一次研究を整理した。既存分野には help-seeking、clarification、learning to defer、メタ認知的制御、人間とAIの相互補完がある。**新しいのはDSCC内の研究区分であり、これらの研究を新規発明として再包装しない。**

既知研究は、質問や専門家への委譲を学習できる例、検索コストを伴う学習から回答保留が得られる例、学習が「いつも頼る」「一切頼らない」へ偏る例を示している。環境・教師信号・回答者の条件は研究ごとに異なる。これらを、そのまま長期の人間・AI共生や普遍的な自己認識の実証とは扱わない。

DSCCで残る問いは、**限界の見積もり、依頼先の選択、相手の負担、回答の検証、経験の継承を接続したとき、適切な協働が未知の条件でも続くか**である。[研究計画](RESEARCH_AGENDA.ja.md)に八つの問いと十二の提案受入条件を記録する。

## 4. 「自発的」と「創発」を区別する

| 区分 | 何を確認するか | それだけでは言えないこと |
|---|---|---|
| 外部ルールによる発火 | 決められた条件で人間確認へ進む | AI自身が相談時点を選んだこと |
| 指示・実演による行動 | プロンプトや実演に従って依頼する | 教えなかった条件へ汎化したこと |
| 明示的な求助学習 | 質問・委譲の良否を報酬や教師信号から学ぶ | 求助と無関係な目的から生じたこと |
| 副次的な能力獲得 | 主目的とは別の、未直接訓練の行動が得られる | 無条件・無教師で能力全体が生じたこと |
| 汎化・機構の検証 | 未見課題・相手・能力変化で追跡し、要因を比較する | 主観的自覚やあらゆる環境での保証 |

本分野の「自発的」は、実行時に人間から毎回『今ここで聞け』と指示されず、エージェントの方策が依頼を選ぶ、という操作的な意味で使う。事前学習・実演・報酬・道具説明の影響が消えるという意味ではない。

研究では、どの行動を直接教えたか、どの補助信号を使ったか、どの条件を評価まで保留したかを明示する。単なる質問回数の増加、丁寧な自己申告、評価尺度の閾値越えを創発の証拠にしない。突然の能力出現を研究計画の前提にも置かない。
