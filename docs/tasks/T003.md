# T003 — WASI executor with enforceable limits

Status: READY
Dependencies: none

## Goal

Add a genuine isolated runtime before accepting arbitrary third-party tools. Implement explicit input mounts, no default network, memory/fuel/deadline limits, output limits and cancellation.

## Edit boundaries

* `src/dscc/executors/`

## Acceptance

Adversarial module cannot read a secret outside mounts, open a network connection, exceed configured memory or loop indefinitely. Tests fail closed if the runtime is absent. Never fall back to subprocess shell execution.
