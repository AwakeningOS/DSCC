## Acceptance

- Preserve old signed bytes/CIDs; validate the draft payload, unique IDs, local endpoints, source pointers and actual reference types.
- Keep source logs, extracts and indexes separately rebuildable; a failed index update keeps the prior working generation.
- Retrieve structurally relevant candidates independently of topic search; do not just rerank semantic top-k.
- Give concrete node/edge mappings, condition differences, source locators and missing evidence with each proposed bridge.
- Preserve unperformed, stopped, unknown, contradictory and corrected paths. Never infer causality from order alone.
- Store attempted transfer as a new assessment referencing the bridge and real trial. Do not promote self-report into independent validation.
- Prevent source-lineage duplication from masquerading as independent evidence.
- Test confidentiality before candidate generation and graph expansion, not only at final display.
- Run the existing regression suite and expand the supplied synthetic contract checks. Synthetic shape tests are not retrieval-quality evidence.
- Evaluate actual unstructured/partially structured traces with project-lineage/time splits and target-prefix queries, including far-topic analogies, same-topic decoys, generic-chain false positives and negative transfer.
- Record retrieval/mapping/source quality, downstream usefulness, cost/latency/RAM and all external model calls. Tune each comparison system naturally; keep the full design's freedom.
