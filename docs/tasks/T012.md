## Implemented local contract lane

`src/dscc/research.py`, ADR-0005 and `docs/RESEARCH_HANDOFF.md` define and implement versioned profiles, without new top-level seed kinds, for:

- ResearchQuestion
- LiteratureReview
- Hypothesis
- ExperimentPlan
- EvaluationRun
- FailureReport
- OpenQuestion / ResearchState
- AgentContribution metadata

The implementation records input Artifact CIDs and declared observable contributor metadata; validates local original-source CID/JSON Pointer references; returns an explicit ResearchState with its complete bounded ancestor closure; preserves typed hypotheses/results and contradiction/supersession assertions; and surfaces exact declared-work duplicate candidates. CLI and MCP expose local record/handoff operations. Regression tests include local cross-node transfer, reopen, real CLI/MCP subprocesses and malformed/tampered inputs.

These synthetic tests do not establish research quality, semantic contradiction/duplicate detection, or successful participation by actual distinct models. Closed-model provider/model/snapshot identifiers remain null when unavailable. No proprietary weights or hidden chain of thought are required.

## First real cross-model experiment — still open

Demonstrate a cross-model handoff on one bounded AI-research question:

1. Agent A surveys primary literature and records known results and an unresolved question.
2. Agent B receives only the DSCC artifacts, not Agent A's conversation state, and designs the next experiment.
3. Agent C or a human evaluates the result and records evidence and remaining uncertainty.
4. A different model resumes from the resulting research state.

Acceptance:
- every handoff is artifact-based;
- primary-source references remain recoverable;
- literature-known answers are distinguished from newly measured results;
- the experiment addresses the recorded unresolved question;
- actual provider/model changes are recorded;
- no hidden chain of thought is required;
- repeated work and conflicting findings are detectable;
- the full-design research workflow is preserved; ablations are derived afterward.
